# FirebirdEncryptionGuide

Documentation and examples for the Firebird encryption plugin.

Guides in PDF format:

| Language | Encryption plugin | Closed-source GUI application, Firebird 3.0, 4.0, 5.0 |
|---|---|---|
| English | [fbcrypt-en.pdf](https://github.com/IBSurgeon/FirebirdEncryptionGuide/releases/latest/download/fbcrypt-en.pdf) | [fbcrypt-closed-gui-en.pdf](https://github.com/IBSurgeon/FirebirdEncryptionGuide/releases/latest/download/fbcrypt-closed-gui-en.pdf) |
| Portuguese (Brazil) | [fbcrypt-pt-br.pdf](https://github.com/IBSurgeon/FirebirdEncryptionGuide/releases/latest/download/fbcrypt-pt-br.pdf) | [fbcrypt-closed-gui-pt-br.pdf](https://github.com/IBSurgeon/FirebirdEncryptionGuide/releases/latest/download/fbcrypt-closed-gui-pt-br.pdf) |
| Polish | [fbcrypt-pl.pdf](https://github.com/IBSurgeon/FirebirdEncryptionGuide/releases/latest/download/fbcrypt-pl.pdf) | [fbcrypt-closed-gui-pl.pdf](https://github.com/IBSurgeon/FirebirdEncryptionGuide/releases/latest/download/fbcrypt-closed-gui-pl.pdf) |
| Russian | [fbcrypt.pdf](https://github.com/IBSurgeon/FirebirdEncryptionGuide/releases/latest/download/fbcrypt.pdf) | [fbcrypt-closed-gui.pdf](https://github.com/IBSurgeon/FirebirdEncryptionGuide/releases/latest/download/fbcrypt-closed-gui.pdf) |

* Example for the closed-source GUI application: [README in English](examples/closed-gui/README.en.md), [README in Russian](examples/closed-gui/README.md).
* Sources of the guides: [doc/en](doc/en), [doc/pt-br](doc/pt-br), [doc/pl](doc/pl), [doc/ru](doc/ru). To build a PDF, run `asciidoctor-pdf fbcrypt.adoc` or `asciidoctor-pdf fbcrypt-closed-gui.adoc` in that folder.
* Examples for Python, Java, PHP, .NET, Free Pascal and C++: [examples](examples/README.md)
