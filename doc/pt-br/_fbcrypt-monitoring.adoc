[[fbcrypt-monitoring]]
= Como acompanhar o andamento da criptografia

O Firebird criptografa o banco de dados somente quando ele tem conexões ativas. O processo de criptografia é executado em uma thread paralela separada. Para bancos de dados grandes, a criptografia completa pode levar bastante tempo.

== Tabela MON$DATABASE

Para acompanhar o processo de criptografia, execute uma consulta SQL na tabela de monitoramento `MON$DATABASE`:

[source,sql]
----
select mon$crypt_page * 100.0 / mon$pages as Percent from mon$database;
commit;
----

O campo `MON$CRYPT_PAGE` contém o número da página a que a thread de criptografia chegou. Quando a criptografia termina, o campo é igual a `0`.

As tabelas de monitoramento mostram um retrato do momento do primeiro acesso na transação. Para ver o novo valor, termine a transação (`commit`) e execute a consulta de novo.

No Firebird 4.0 e 5.0, também existe o campo `MON$CRYPT_STATE`:

[source,sql]
----
select mon$crypt_state from mon$database;
----

[cols="1,3", options="header"]
|===
| Valor | Estado
| `0` | o banco de dados não está criptografado
| `1` | o banco de dados está criptografado
| `2` | descriptografia em andamento
| `3` | criptografia em andamento
|===

== isql

O comando `show database` mostra uma destas linhas:

[cols="2,3", options="header"]
|===
| Linha | Estado
| `Database not encrypted` | o banco de dados não está criptografado
| `Database encrypted, crypt thread not complete` | a criptografia foi iniciada, mas não terminou
| `Database encrypted` | a criptografia terminou
|===

== gstat

O comando `gstat -h` mostra os atributos do cabeçalho: o indicador `encrypted`, o nome do plugin e o nome da chave. Ele é rápido.

O comando `gstat -e` também conta as páginas criptografadas e não criptografadas:

== Se a criptografia não avança

* Verifique se há pelo menos uma conexão com o banco de dados. Sem conexões, a thread de criptografia não funciona.
* Verifique se a conexão enviou a chave ou se a chave está disponível para o servidor.
* Veja as mensagens no `firebird.log`.
