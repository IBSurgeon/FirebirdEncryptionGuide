= Как отслеживать ход шифрования

Firebird шифрует базу данных только тогда, когда у неё есть активные соединения. Процесс шифрования выполняется в отдельном параллельном потоке, и для больших баз данных полное шифрование может занять значительное время.

Чтобы отслеживать процесс шифрования, выполните любой из SQL-запросов из `MON$`:

[source,sql]
----
select mon$crypt_page * 100.0 / mon$pages as Percent from mon$database;
commit;
----
