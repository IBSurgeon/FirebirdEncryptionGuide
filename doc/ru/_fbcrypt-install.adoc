[[fbcrypt-install]]
= Установка плагина шифрования

Поддерживаются Firebird 3.0 (начиная с 3.0.3), 4.0 и 5.0. Firebird 2.5 не поддерживается: в нём нет интерфейса плагинов шифрования.

[NOTE]
====
Если у вас установлен HQbird, скачивать архив плагина и копировать его файлы не нужно: они входят в HQbird. Нужны только файл лицензии `DbCrypt.conf` и параметр `KeyHolderPlugin`. См. раздел <<fbcrypt-install-hqbird>>.
====

Установка состоит из одних и тех же шагов для всех платформ:

. Скопировать файлы плагина в каталог Firebird.
. Положить файл лицензии `DbCrypt.conf` в каталог `plugins`.
. Задать параметр `KeyHolderPlugin = KeyHolder` в `firebird.conf` или `databases.conf`.
. Перезапустить Firebird.
. Проверить шифрование на тестовой базе данных.

[[fbcrypt-install-hqbird]]
== Если установлен HQbird

HQbird уже содержит файлы плагина шифрования для сервера и для рабочих мест. Скрипты установки запускать не нужно. Архив плагина скачивать не нужно. Каталоги `Server` и `Client` из архива копировать не нужно.

.Файлы плагина в HQbird для Windows
[cols="1,1", options="header"]
|===
| Файлы | Каталог

| Серверные плагины `dbcrypt.dll`, `keyholder.dll`, `keyholderstdin.dll`
| `C:\HQbird\Firebird<NN>\plugins`

| Библиотеки `fbclient.dll` и `fbcrypt.dll`, утилиты `gbak`, `nbackup`, `isql`, `gfix`
| `C:\HQbird\Firebird<NN>`

| Клиентские файлы для рабочих мест: `fbclient.dll`, `fbcrypt.dll`, OpenSSL, `plugins\keyholder.dll`, `plugins\keyholderstdin.dll`, `plugins\dbcrypt.dll`
| `C:\HQbird\ClientLibs\<разрядность>\<версия>`, например `C:\HQbird\ClientLibs\64\5.0`
|===

Здесь `C:\HQbird` — каталог установки по умолчанию, `<NN>` — `30`, `40` или `50`.

Что нужно сделать:

. Положите файл лицензии `DbCrypt.conf` в каталог `plugins` сервера.
. Задайте параметр `KeyHolderPlugin = KeyHolder` в `firebird.conf` или `databases.conf`. В файле `firebird.conf` из HQbird этот параметр закомментирован.
. Перезапустите Firebird.
. Зашифруйте базу данных: см. <<fbcrypt-usage>>.
. Для рабочего места возьмите файлы из каталога `ClientLibs` нужной разрядности и версии. В файле `firebird.conf` рядом с `fbclient.dll` задайте `KeyHolderPlugin = KeyHolder`.

Тестовой библиотеки `KeySource.dll` и скрипта `run-tests.ps1` в HQbird нет. Они есть только в архиве плагина и нужны только для проверки.

[NOTE]
====
64-битному клиентскому плагину `KeyHolder` нужна библиотека OpenSSL с именем `libcrypto-1_1-x64.dll` рядом с `fbclient.dll`. Если в каталоге `ClientLibs\64\5.0` такого файла нет, скопируйте его из каталога `ClientLibs\64\4.0`. Без этого файла подключение завершается ошибкой `Key not set`, даже когда библиотека `KeySource.dll` вернула верный ключ.
====

== Windows

=== Установка плагина шифрования на Windows из скрипта

Загрузите 2 файла с https://github.com/IBSurgeon/FirebirdEncryptionPluginInstall/tree/main/ForWindows: `install-Firebird-encryption-plugin.bat` и `inst-crypt-plugin.ps1`

Для упрощения развёртывания плагина шифрования мы подготовили скрипт на языке PowerShell. Он автоматически производит поиск установленных экземпляров Firebird, скачивает нужный архив с плагином, распаковывает архив, вносит изменения в файл конфигурации и запускает тесты шифрования для проверки работоспособности плагина.

Запускаем командную строку `cmd` от имени администратора и переходим в директорию расположения скрипта `install-Firebird-encryption-plugin.bat`.

[source,cmd]
----
cd d:\IBase\crypt-plugin
----

Теперь можно выполнить скрипт инсталляции плагина:

[source,cmd]
----
install-Firebird-encryption-plugin.bat
----

Будет выведено следующее сообщение:

----
This script will install Firebird crypt plugin.
Now script will scan OS registry for Firebird installations.
You can run script silently adding --crypt="c:\path\to\firebird" parameter
(Do not forget double-quotes in path like "C:\Program Files", etc...)
Press Enter to continue or Ctrl+C to exit script.
----

Если вы нажмёте `Enter`, то установщик ищет установленный Firebird в реестре и предлагает выбрать, в какой экземпляр следует установить плагин. Он проверяет наличие совместимой версии Firebird (3.0.3+, 4.0.x, 5.0.x).

Вы также можете нажать `Ctrl+C`, выйти и запустить команду заново с дополнительным ключом.

Сначала попробуем нажать Enter.

В качестве альтернативы вы можете явно указать путь к корневой папке Firebird, для которого будет установлен плагин шифрования:

[source,cmd]
----
install-Firebird-encryption-plugin.bat --crypt="C:\Firebird\5.0"
----

После чего инсталлятор выполнит следующие шаги:

* *Автоматическая загрузка файлов* +
Установщик загружает необходимые файлы (dll-файлы, конфигурационные файлы и пробную лицензию), а затем сохраняет их в выбранную папку Firebird.

* *Изменение firebird.conf* +
Установщик изменяет `firebird.conf` — добавляет строку `KeyHolderPlugin = KeyHolder`

* *Перезапуск Firebird (будьте осторожны в рабочей среде!)* +
Установщик перезапускает экземпляр Firebird. На этом этапе Firebird готов шифровать базы данных, используя пробную лицензию.

* *Создает папки с файлами для клиентских приложений* +
Установщик создает папку с клиентскими файлами в папке, где он был запущен: `Client\32bit` и `Client\64bit`.
+
Эти файлы можно использовать для разработки приложения, которое будет использовать шифрование: скопируйте все файлы из этой папки в папку, где находится исполняемый файл вашего приложения. Очень важно использовать предоставленный файл `fbclient.dll`.

[WARNING]
====
В клиентском пакете (`Client\32bit\key-plugins` и `Client\64bit\key-plugins`) присутствует динамическая библиотека `KeySource.dll`. В этой динамической библиотеке находится функция, возвращающая тестовый ключ, который был использован для тестирования шифрования. Этот тестовый ключ передаётся плагину `KeyHolder`. Вы не должны использовать эту динамическую библиотеку в производственной системе. Следует реализовать её самостоятельно. Подробности описаны в <<fbcrypt-keysource>>.
====

=== Ручная установка

В некоторых случаях установку скриптом сделать не удаётся, например если Firebird работает на нестандартном порту. В этом случае вы можете установить плагин шифрования вручную. Для этого необходимо скачать zip архив инсталлятора для соответствующей версии по одному из адресов:

* https://cc.ib-aid.com/download/distr/crypt/CryptPlugin-FB_30_WINDOWS_64bit.zip
* https://cc.ib-aid.com/download/distr/crypt/CryptPlugin-FB_40_WINDOWS_64bit.zip
* https://cc.ib-aid.com/download/distr/crypt/CryptPlugin-FB_50_WINDOWS_64bit.zip

Внутренняя структура архива выглядит следующим образом:

Это состав архива для Firebird 5.0 от 26.11.2026. Архивы этой даты содержат файлы HQbird 3.0.15.33894, 4.0.8.3332 и 5.0.5.1979 и пробную лицензию, которая действует до 31.12.2026. В архиве для Firebird 3.0 другие библиотеки ICU (`icu*52`) и C++ (`msvcp100.dll`, `msvcr100.dll`).

Каталог `Server` в архиве содержит бинарные файлы *ТОЛЬКО* для архитектуры x64, предполагая, что серверная установка имеет именно такую архитектуру, что практически всегда верно. Каталог `Client` в архиве содержит бинарные файлы как для архитектуры x86 (32bit), так и для x64 (64bit).

Файлы из каталога `Server` необходимо распаковать в корневую директорию сервера Firebird. Часть бинарных файлов Firebird будет заменена. Перед копированием остановите службу Firebird.

Каталог `Client` содержит два подкаталога `Client\32bit` и `Client\64bit`. Файлы из этих каталогов можно использовать для разработки приложения, которое будет использовать шифрование: скопируйте все файлы из этой папки в папку, где находится исполняемый файл вашего приложения. Очень важно использовать предоставленный файл `fbclient.dll`.

Каталог `key-plugins` содержит два источника ключа. Нужный файл скопируйте сами:

[cols="2,3,4", options="header"]
|===
| Файл | Куда скопировать | Назначение
| `KeySource.dll` | в каталог клиента, рядом с `fbclient.dll` | Тестовая библиотека с тестовыми ключами. Ключ получают приложение и утилиты без переключателей. См. <<fbcrypt-keysource>>.
| `keyholderstdin.dll` | в каталог `plugins` клиента | Плагин `KeyHolderStdin`: утилита читает ключ из входного потока. См. <<fbcrypt-utils-stdin>>.
|===

Без копирования утилита с переключателем `-KeyHolder KeyHolderStdin` сообщает `Key holder plugin KeyHolderStdin failed to load`.

В каталоге `Client/db-crypt` находятся скрипт для проверки шифрования и тестовая база данных.

==== Настройка

После распаковки архива вам необходимо произвести настройку Firebird.

Для включения плагина шифрования базы данных и управления ключами необходимо указать имя плагина управления ключами в конфигурационном файле `firebird.conf`:

[source,conf]
----
KeyHolderPlugin = KeyHolder
----

Или, в качестве альтернативы, в файле `databases.conf` укажите псевдоним зашифрованной базы данных:

[source,conf]
----
myencrypted = C:\Temp\EMPLOYEE30\EMPLOYEE30.FDB
{
    KeyHolderPlugin = KeyHolder
}
----

Во втором случае подключайтесь к базе данных по псевдониму (`localhost:myencrypted`).

После изменения конфигурации перезапустите службу Firebird.

==== Тестирование

После установки и конфигурирования вы можете провести ряд тестов для проверки работоспособности шифрования и дешифрования. Тесты находятся в папке `Client/db-crypt`.

[NOTE]
====
В архивах от 01.10.2026 и новее вместо файлов `01-encrypt.bat` ... `05-gfix.bat` находится один скрипт `run-tests.ps1`. Он выполняет те же шаги два раза: с ключом из библиотеки `KeySource.dll` и с ключом из входного потока (плагин `KeyHolderStdin`). Перед каждым проходом скрипт копирует нужный файл из каталога `key-plugins` и меняет параметр `KeyHolderPlugin` в файле `firebird.conf` клиента. Команды, которые он выполняет, описаны ниже.
====

[WARNING]
====
Все тесты выполняются с использованием тестовых ключей. Если в вашей установке тестовые ключи расположены в файле `%root%/plugins/KeyHolder.conf`, то этот файл предназначен только для тестовых целей. Не забудьте переименовать или удалить его, когда завершите тесты.
====

== Linux

Скрипты для установки Firebird и плагина шифрования под Linux расположены по адресу https://github.com/IBSurgeon/firebirdlinuxinstall

Для установки на "ванильные" версии Firebird используется один из скриптов с именем `fb_vanilla-<version>.sh`. Например, для Firebird 5.0 это файл https://raw.githubusercontent.com/IBSurgeon/firebirdlinuxinstall/refs/heads/main/fb_vanilla-50.sh[fb_vanilla-50.sh].

[source,bash]
----
wget https://raw.githubusercontent.com/IBSurgeon/firebirdlinuxinstall/refs/heads/main/fb_vanilla-50.sh
chmod +x fb_vanilla-50.sh
sudo ./fb_vanilla-50.sh
----

Будет выведено следующее сообщение:

----
This program will install Firebird 5.0 on this computer
    Command line switches:
    --debug - also install debug information, takes more traffic;
    --crypt - install and configure crypto plugin
    --crypt-only[=/path/to/firebird] - install and configure ONLY crypto plugin without Firebird
Press Enter to start installation or ^C to abort
----

Переключатель `--crypt` устанавливает Firebird вместе с плагином шифрования. Переключатель `--crypt-only` устанавливает только плагин в уже установленный Firebird:

[source,bash]
----
sudo ./fb_vanilla-50.sh --crypt-only=/opt/firebird
----

[NOTE]
====
Скрипт не устанавливает пакет совместимости OpenSSL 1.1 и не создаёт файл с ключами. Если после работы скрипта шифрование не запускается, выполните шаги ручной установки, описанные ниже.
====

=== Ручная установка на Linux

Шаги ниже проверены на AlmaLinux 9 с Firebird 3.0, 4.0 и 5.0, установленными в `/opt/firebird`. Все команды выполняются от имени `root`.

Различия между версиями:

[cols="3,1,1,1", options="header"]
|===
| | FB 3.0 | FB 4.0 | FB 5.0
| Архив `CryptPlugin-FB_<V>_LINUX_64bit.tar.xz` | `30` | `40` | `50`
| Нужен OpenSSL 1.1 | да | да | нет (OpenSSL 3)
| Имя службы systemd | `firebird-superserver` | `firebird` | `firebird`
| Зашифрованная копия стандартным `gbak` | нет | да | да
| `MON$DATABASE.MON$CRYPT_STATE` | нет | да | да
|===

.Шаг 1. Задайте версию
[source,bash]
----
V=50      # 30 = Firebird 3.0, 40 = Firebird 4.0, 50 = Firebird 5.0
FB=/opt/firebird
----

.Шаг 2. Скачайте и распакуйте архив
[source,bash]
----
cd /root
curl -LO https://cc.ib-aid.com/download/distr/crypt/CryptPlugin-FB_${V}_LINUX_64bit.tar.xz
mkdir -p /root/crypt
tar xJf CryptPlugin-FB_${V}_LINUX_64bit.tar.xz -C /root/crypt --strip-components=1
ls /root/crypt/Server/plugins
----

В каталоге `Server/plugins` находятся файлы `libDbCrypt.so`, `libKeyHolder.so` и `DbCrypt.conf` (пробная лицензия). Каталог `Client` содержит клиентские утилиты и библиотеки.

.Шаг 3. Установите OpenSSL 1.1 (только Firebird 3.0 и 4.0)
[source,bash]
----
dnf install -y compat-openssl11
ls /usr/lib64/libcrypto.so.1.1
----

Плагины для Firebird 3.0 и 4.0 загружают `libcrypto.so.1.1`. Без этой библиотеки оператор `ALTER DATABASE ENCRYPT` завершится ошибкой `Library libcrypto.so.1.1 failed to load`. В Debian и Ubuntu пакет называется иначе; установите пакет, который содержит `libcrypto.so.1.1`.

В стандартных репозиториях Ubuntu 22.04 и 24.04 нет пакета с OpenSSL 1.1. При проверке архивов от 26.11.2026 на Ubuntu 24.04 пакет `libssl1.1` из Ubuntu 20.04 установили командой `dpkg -i`. С этим пакетом скрипт `Client/db-crypt/run-tests.sh` прошёл для Firebird 3.0, 4.0 и 5.0. В Debian и Ubuntu библиотека находится в каталоге `/usr/lib/x86_64-linux-gnu`.

.Шаг 4. Скопируйте файлы плагина
[source,bash]
----
cp /root/crypt/Server/plugins/* $FB/plugins/
ls -l $FB/plugins | grep -iE 'crypt|key'
----

.Шаг 5. Создайте файл с ключом (для проверки)
[source,bash]
----
KEY=$(openssl rand -hex 32 | sed 's/../0x&,/g')
echo "Key=Red $KEY" > $FB/plugins/KeyHolder.conf
chown root:firebird $FB/plugins/KeyHolder.conf
chmod 640 $FB/plugins/KeyHolder.conf
----

Сохраните копию ключа вне сервера. Файл с ключом на одном диске с базой данных подходит только для проверки и разработки.

.Шаг 6. Включите плагин управления ключами

Для одной базы данных (`databases.conf`):

[source,bash]
----
cat >> $FB/databases.conf <<'EOF'

employee = /opt/firebird/examples/empbuild/employee.fdb
{
    KeyHolderPlugin = KeyHolder
}
EOF
----

Или для всех баз данных (`firebird.conf`):

[source,bash]
----
echo "KeyHolderPlugin = KeyHolder" >> $FB/firebird.conf
----

Второй вариант необходим, если вы восстанавливаете зашифрованную резервную копию в новый файл.

.Шаг 7. Перезапустите Firebird
[source,bash]
----
# Firebird 3.0:
systemctl restart firebird-superserver
# Firebird 4.0 и 5.0:
systemctl restart firebird
----

.Шаг 8. Зашифруйте тестовую базу данных
[source,bash]
----
$FB/bin/isql localhost:employee -user SYSDBA -password masterkey <<'EOF'
alter database encrypt with "DbCrypt" key Red;
commit;
show database;
EOF
----

Имя плагина `"DbCrypt"` на Linux зависит от регистра. Не удаляйте двойные кавычки.

.Шаг 9. Проверьте результат
[source,bash]
----
$FB/bin/gstat -h /opt/firebird/examples/empbuild/employee.fdb | grep -iE 'attrib|key name'
#   Attributes      force write, encrypted, plugin DbCrypt
#   Encryption key name:    RED
----

.Шаг 10. Проверьте, что ключ необходим
[source,bash]
----
mv $FB/plugins/KeyHolder.conf $FB/plugins/KeyHolder.conf.off
systemctl restart firebird            # firebird-superserver для 3.0
echo "select count(*) from employee;" | $FB/bin/isql localhost:employee -user SYSDBA -password masterkey
#   Statement failed, SQLSTATE = 08006
#   Invalid crypt key RED
#   -Key not set
mv $FB/plugins/KeyHolder.conf.off $FB/plugins/KeyHolder.conf
systemctl restart firebird            # firebird-superserver для 3.0
----

Резервное копирование на Linux описано в <<fbcrypt-utils-gbak>>.

== Файл лицензии

Плагин `DbCrypt` работает только с файлом лицензии `plugins/DbCrypt.conf`. Архивы содержат пробную лицензию с ограниченным сроком действия. Для рабочей системы замените файл на лицензию, полученную от IBSurgeon, и перезапустите Firebird.

Файл лицензии нужен везде, где загружается плагин `DbCrypt`: на сервере и рядом с утилитой `gbak`, которая создаёт зашифрованные резервные копии.

Параметры файла описаны в <<fbcrypt-config-dbcrypt>>.
