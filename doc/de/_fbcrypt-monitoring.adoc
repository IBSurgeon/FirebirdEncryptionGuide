[[fbcrypt-monitoring]]
= Wie Sie den Fortschritt der Verschlüsselung verfolgen

Firebird verschlüsselt die Datenbank nur, wenn sie aktive Verbindungen hat. Der Verschlüsselungsprozess läuft in einem eigenen parallelen Thread. Bei großen Datenbanken kann die vollständige Verschlüsselung lange dauern.

== Die Tabelle MON$DATABASE

Um den Verschlüsselungsprozess zu verfolgen, führen Sie eine SQL-Abfrage auf die Monitoring-Tabelle `MON$DATABASE` aus:

[source,sql]
----
select mon$crypt_page * 100.0 / mon$pages as Percent from mon$database;
commit;
----

Das Feld `MON$CRYPT_PAGE` enthält die Nummer der Seite, die der Verschlüsselungs-Thread erreicht hat. Wenn die Verschlüsselung abgeschlossen ist, ist der Wert des Feldes `0`.

Die Monitoring-Tabellen zeigen den Stand zum Zeitpunkt des ersten Zugriffs in der Transaktion. Um einen neuen Wert zu sehen, beenden Sie die Transaktion (`commit`) und führen Sie die Abfrage erneut aus.

In Firebird 4.0 und 5.0 gibt es auch das Feld `MON$CRYPT_STATE`:

[source,sql]
----
select mon$crypt_state from mon$database;
----

[cols="1,3", options="header"]
|===
| Wert | Zustand
| `0` | die Datenbank ist nicht verschlüsselt
| `1` | die Datenbank ist verschlüsselt
| `2` | die Entschlüsselung läuft
| `3` | die Verschlüsselung läuft
|===

== isql

Der Befehl `show database` zeigt eine dieser Zeilen:

[cols="2,3", options="header"]
|===
| Zeile | Zustand
| `Database not encrypted` | die Datenbank ist nicht verschlüsselt
| `Database encrypted, crypt thread not complete` | die Verschlüsselung ist gestartet, aber nicht abgeschlossen
| `Database encrypted` | die Verschlüsselung ist abgeschlossen
|===

== gstat

Der Befehl `gstat -h` zeigt die Attribute des Headers: das Kennzeichen `encrypted`, den Plugin-Namen und den Schlüsselnamen. Er arbeitet schnell.

Der Befehl `gstat -e` zählt zusätzlich die verschlüsselten und die nicht verschlüsselten Seiten:

== Wenn die Verschlüsselung nicht fortschreitet

* Prüfen Sie, dass es mindestens eine Verbindung zur Datenbank gibt. Ohne Verbindungen arbeitet der Verschlüsselungs-Thread nicht.
* Prüfen Sie, dass die Verbindung den Schlüssel gesendet hat oder dass der Schlüssel für den Server verfügbar ist.
* Sehen Sie sich die Meldungen in `firebird.log` an.
