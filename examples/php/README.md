# Примеры для PHP

Расширение: `pdo_firebird`. Оно работает через `fbclient` (ISC API).
В PHP нет параметра подключения для ключа шифрования. Ключ передаёт клиентская библиотека.

## Что нужно

- PHP 8.2 или новее с расширением `pdo_firebird` (проверено с PHP 8.4.28, NTS, x64).
- Для примера `pdo-ffi-fbcrypt`: расширение `ffi`.
- Тестовый сервер: см. [../common/README.md](../common/README.md). Перед запуском загрузите `test-env.ps1`.

Файл [php.ini](php.ini) включает нужные расширения. Запускайте примеры с ключом `-c ..\php.ini`.

## Главное условие

PHP должен загрузить `fbclient` из клиентского пакета плагина шифрования.
На Windows поставьте каталог клиента первым в `PATH`:

```powershell
$env:PATH = "$env:FBCRYPT_CLIENT;$env:PATH"
```

Если PHP загрузит другой `fbclient`, ключ не будет передан.

## Примеры

| Каталог | Способ | Что показывает |
|---|---|---|
| [pdo-keysource](pdo-keysource) | C | В скрипте нет кода для ключа. Ключи отдаёт библиотека `KeySource`. Основной способ. |
| [pdo-ffi-fbcrypt](pdo-ffi-fbcrypt) | E | Библиотека `fbcrypt` через FFI. Один ключ, два ключа, замена ключей, ошибки. |
| [gbak-stdin](gbak-stdin) | — | Запуск `gbak` из скрипта. Ключ передаётся в стандартный ввод процесса. |

Оба способа используют защищённый обмен ключом. Параметр `UnsafeClient = true` на сервере не нужен.

Запуск:

```powershell
cd pdo-ffi-fbcrypt
```

```powershell
php -c ..\php.ini main.php
```

Проверка: `.\run-test.ps1` в каталоге примера. Скрипт сам добавляет каталог клиента в `PATH`.

## Способ C: KeySource

1. Соберите библиотеку `KeySource` (см. [../keysource](../keysource)).
2. Создайте клиентский каталог: `..\common\new-keysource-client.ps1 -KeySourceDll <файл>`.
3. Поставьте каталог `client-keysource` первым в `PATH` веб-сервера или `php-fpm`.

Код приложения не меняется. Тот же способ подходит для расширения `php-firebird` (`ibase_connect`): оно тоже вызывает `isc_attach_database`. С `ibase_connect` способ не проверялся.

## Способ E: FFI и fbcrypt

Порядок вызовов:

1. `fbcrypt_init(<путь к fbclient>)` — путь к той же библиотеке, которую загрузил PHP.
2. `fbcrypt_callback(NULL)` — один раз в процессе.
3. `fbcrypt_key(<имя>, <значение>, <длина>)` — для каждого ключа.
4. `new PDO(...)`.

Ограничения:

- Расширение FFI должно быть разрешено (`ffi.enable = true`). В веб-окружении это снижает защиту PHP. Используйте `ffi.enable = preload` или способ C.
- Обратный вызов действует для потока. Сборки NTS (CLI, `php-fpm`) работают в одном потоке. Сборки ZTS не проверялись.
- Постоянные подключения (`PDO::ATTR_PERSISTENT`) не проверялись.

## Где хранить ключ на веб-сервере

- Вне корневого каталога сайта.
- В файле, который читает только учётная запись веб-сервера (`php-fpm`, Apache).
- Не в исходном коде и не в системе контроля версий.

## gbak и версия Firebird

- Firebird 4.0 и 5.0: `gbak -KeyHolder KeyHolderStdin`, ключ в стандартном вводе.
- Firebird 3.0: пример создаёт временный файл ключа и вызывает `gbak -KEYFILE`. Этот вариант на сервере 3.0 не проверен.
