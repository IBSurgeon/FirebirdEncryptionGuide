# Настройка сервера для способа D (статическое значение ключа)

Способ D используют драйверы, которые не выполняют защищённый обмен ключом:

- Jaybird (Java): свойство `dbCryptConfig`;
- Firebird .NET Provider: параметр `crypt key`;
- Python `firebird-driver`: параметр `crypt_callback` со своим классом.

Драйвер отправляет серверу строку `<имя>:0x..,0x..,`. Ключ в ней не защищён.

## Что настроить

| Файл | Параметр | Зачем |
|---|---|---|
| `plugins/KeyHolder.conf` | `UnsafeClient = true` | Плагин `KeyHolder` принимает ключ без защищённого обмена. |
| `firebird.conf` | `WireCrypt = Required` | Сервер отклоняет подключения без шифрования протокола. |
| `firebird.conf` | `AuthServer = Srp256, Srp` | Шифрование протокола работает только с аутентификацией Srp. |

После изменения перезапустите Firebird.

## Предупреждения

- Без `WireCrypt = Required` ключ виден в сетевом трафике.
- Параметр `UnsafeClient = true` действует для всех клиентов этого сервера.
- Не записывайте ключ в исходный код и в файлы настроек приложения. Читайте его из защищённого файла, переменной окружения или хранилища секретов.

## Как проверить

При `UnsafeClient = false` подключение способом D завершается ошибкой:

```
Too long reply from callback >1Mb
```

Способы A, B и C работают при любом значении `UnsafeClient`.
Если все клиенты используют способы A, B или C, оставьте `UnsafeClient = false`.
